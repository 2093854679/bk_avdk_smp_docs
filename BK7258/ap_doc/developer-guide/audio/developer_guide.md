# **音频应用开发指南**

<a id="id2"></a>

## **1\. 简介**

> 本文档是音频应用开发的 `必读文档` 。
>
> 为方便客户使用音频功能，避免直接调用驱动接口开发，降低音频应用的开发难度， `<source code>/ap/components/` 路径下已经提供了一些常见的音频功能组件，例如：录音、播放、语音通话等。
>
> 同时为了满足客户多元化的音频应用需求，也提供了音频开发框架，该框架基于pipeline结构设计，将常见的音频功能封装成一个个独立的功能子模块，客户可以基于该框架，直接调用子功能模块开发自己的音频应用。
