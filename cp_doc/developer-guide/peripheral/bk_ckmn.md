# CKMN 使用指南

<a id="id1"></a>

## 概述

CKMN（Clock Monitor）用于监测时钟信号，支持时钟丢失检测与相关中断。

> - API 参考：[CKMN](../../api-reference/peripheral/bk_ckmn.md)

<a id="id2"></a>

## 相关代码路径

> - API 头文件：`include/driver/ckmn.h`
> - 驱动实现：`middleware/driver/ckmn/`
