# Touch 使用指南



## 概述

Touch 模块支持电容触摸通道的校准、扫描与中断。可用于按键或低功耗唤醒。

> - API 参考：[TOUCH](../../api-reference/peripheral/bk_touch.md "../../api-reference/peripheral/bk_touch.md")
> - 低功耗唤醒：[设置touch作为唤醒源-系统进入深度睡眠以及睡眠模式配置说明](../power_save/bk_touch_sleep.md "../power_save/bk_touch_sleep.md")

> - 驱动实现：`middleware/driver/touch/`
