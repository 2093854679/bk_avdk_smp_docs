# p2p

<a id="id1"></a>

## 1\. 概述

Wi-Fi P2P 功能示例。AP、CP 均需开启 `CONFIG_P2P`。

- 开发者指南：[Wi-Fi P2P](../../../developer-guide/wifi/bk_wifi_p2p.md)

<a id="id2"></a>

## 2\. 编译

```
make bk7259 PROJECT=wifi/p2p
```

<a id="id3"></a>

## 3\. 运行

通过 AP 核 CLI 进行 P2P 操作，详见开发者指南与串口 log 说明。
